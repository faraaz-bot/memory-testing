\section{Introduction}

This document contains notes for computing real-to-real FFTs (like
sine transforms) for \texttt{rocFFT}.


As way of reference, the FFT of complex inputs $\{x_n\}_{n=0}^{N-1}$
is
\begin{dmath}
  X_k = \sum_{k=0}^{N-1} x_n \omega_N^{nk}
\end{dmath}
with $\omega_N=e^{\frac{-2 \pi i}{N}}$.


\section{DST}

\subsection{DCT-I}

\begin{dmath}
  X_k = \frac{1}{2}\( x_0 + \(-1\)^k x_{N-1}\)
  + \sum_{n=1}^{N-2} x_n \cos\left[ \frac{\pi}{N-1} n k \right]
\end{dmath}

This can be computed via FFT on inputs of length $4N-4$ with
\begin{align}
  \tilde{x}_0 &= 0 \\
  \tilde{x}_n &= x_n, \qquad n = 1, \dots, N-2\\
  \tilde{x}_{N-1} &= x_{N-1}\\
  \tilde{x}_{2N-2-n} &= x_n, \qquad n = 1, \dots, N-2\\
  \tilde{x}_{2N-2} &= x_{0}\\
  \tilde{x}_{2 N - 2 + n} &= x_n, \qquad n = 1, \dots, N-2 \\
  \tilde{x}_{3N-3} &= x_{N-1}\\
  \tilde{x}_{4  N - 4 - n} &= x_n, \qquad n = 1, \dots, N-2
\end{align}
and taking the real part of the output first $N$ even-indexed outputs.

\subsection{DST-I}


Given $\{x_n\}_{n=0}^{N-1}$,
\begin{dmath}
  \label{dst1}
  X_k = \sum_{n=0}^{N-1}x_n \sin\left[\frac{\pi}{N+1}(n+1)(k+1)\right]
\end{dmath}

This is equivalent to the negative imaginary part of the DFT of the
length-$2N+2$ sequence
\begin{dmath}
  \tilde{x}
  = \{0, x_0, x_1, \dots, x_{N-1}, 0, -x_{N-1}, \dots, -x_1, -x_0\}
  = \left\{
  \begin{array}{ll}
    0, & n = 0\\
    x_{n-1}, & n = 1, \dots, N\\
    0, & n = N + 1\\
    -x_{2N-n+1}, & n = N+2, \dots, 2N +1
  \end{array}
  \right.
\end{dmath}
and taking the imaginary part of the output indices $1,\dots,N$.

From \cite{FFTW05}, FFTW uses the length-$2N+$ method for computing
the DST-I and DCT-I.  This can be observed in practice with FFTW 3.3.8
by looking at the memory use for the type-I transform as compared to
the memory use for type-II transforms.  If $N$ is odd, it may be
posible to use the standard half-folding algorithm to improve this.
In particular, it seems that $N=2^M-1$ is amenable to attack.\footnote{\href{https://github.com/FFTW/fftw3/blob/16164a7bf3257376f22ddeda0842805d1c456b01/reodft/reodft00e-splitradix.c#L22-L32}{FFTW comment on recursive DST-I.}}

The algorithm given in \cite{vectorzingffts} has poor numerical
properties\footnote{
  \href{https://github.com/FFTW/fftw3/blob/master/reodft/rodft00e-r2hc.c#L22-L40}{FFTW
    comment on numerical precision.}}  and involves a recursion
relationship for computing the outputs, which would have poor
performance on the GPU.

From
\href{https://github.com/FFTW/fftw3/blob/master/reodft/reodft00e-splitradix.c#L22}{github.com/FFTW/fftw3/blob/master/reodft/reodft00e-splitradix.c},
this can be computed recursively as a DST-I when the problem length
$N=2^m-1$.

One other possibly route of attack would be to use a paired-type
algorithm, using the linearity of the FFT.  I was unable to find
references to this in the literature.

From Van Loan (equqation 4.4.2, p 229), we have ``the'' DST:
\begin{dmath}
  y_k = \sum_{j=1}^{m-1} x_j \sin\frac{k j \pi}{m}
\end{dmath}
for $\{x_j\}_{j=1}^{m-1}$, $\{y_k\}_{k=1}^{m-1}$.  We can re-index
from $0$ to $N-1$ and we do end up with equation~\eqref{dst1}.
Algorithm 4.4.2 on page 238 uses a paired real/complex transform to
compute this, and then post-processes the result by dividing by sines.
This algorithm requires $2.5 N \log N$ flops; roughly the same cost as
a real-to-complex FFT of length $N$.

\subsection{DCT-II}

\begin{dmath}
  X_k = \sum_{n=0}^{N-1} x_n \cos\left[\frac{\pi}{N} \(N + \frac{1}{2}\) k\right]
\end{dmath}

This can be computd by taking via a length-$4N$ FFT with input, for
$n=0,\dots,N-1$,
\begin{align}
  \tilde{x}_{2n} &= 0 \\
  \tilde{x}_{4N -2n -2} &= 0.0\\
  \tilde{x}_{2n + 1} &= x_n\\
  \tilde{x}_{4N -(2n + 1)} &= x[n]
\end{align}

From \cite{shaojohnsondst23}, this can be computed via a length $N$
real/complex FFT for even $N$.  Define
$\left\{y_n\right\}_{n=0}^{N-1}$ via
\begin{align}
  y_n &= x_{2 n} \\
  y_{N - 1 -n} &= x_{2 n + 1}
\end{align}
for $n = 0, \dots, N/2 -1 $ and let $Y=\mathcal{F}\left[y\right]$.  Then,
\begin{align}
  X_{0} &= \Re{Y_0} \\
  X_{k} &= \Re{\omega_{4N}^k Y_k}, \qquad k = 1,\dots, N/2-1 \\
  X_{N-k} &= -\Im{\omega_{4N}^k Y_k}, \qquad k = 1,\dots, N/2-1 \\
  X_{N / 2} &= \Re{Y_{N/2}}/\sqrt(2)
\end{align}

To show this, we note that, for real $x_n$,
\begin{dmath}
  \(X_k\)^*
  = \(\sum_{n=0}^{N-1} x_n \omega_N^{nk} \)^*
  = \sum_{n=0}^{N-1} x_n \omega_N^{-nk}
  = \sum_{n=0}^{N-1} x_{N-1-n} \omega_N^{nk}.
\end{dmath}
Then, 
\begin{dmath}
  \sum_{n=0}^{4N-1} \tilde{x}_n \omega_{4N}^{nk}
  = \sum_{n=0}^{2N-1} \cancelto{0}{\tilde{x}_{2n}}\quad \omega_{4N}^{2nk}
  + \sum_{n=0}^{2N-1} \tilde{x}_{2n+1} \omega_{4N}^{(2n+1)k}
  %% = \sum_{n=0}^{N-1} x_n \omega_{4N}^{(2n+1)k}
  %% + \sum_{n=N}^{2N-1} x_{N-n-1} \omega_{4N}^{(2n+1)k}
  = \sum_{n=0}^{N-1} x_n \omega_{4N}^{(2n+1)k}
  + \sum_{n=0}^{N-1} x_{N-n-1} \omega_{4N}^{(2(n+N)+1)k}
  =
  \omega_{4N}^{k}
  \left[
  \sum_{n=0}^{N-1} x_n \omega_{2N}^{nk}
  + \sum_{n=0}^{N-1} x_{n} \omega_{2N}^{-nk}
  \right]
  =
  \omega_{4N}^{k}
  \left[
  \sum_{n=0}^{N-1} x_n \(\omega_{2N}^{nk} + \omega_{2N}^{-nk} \)
  \right]
  =
  \omega_{4N}^{k}
  \left[
  \sum_{n=0}^{N-1} x_n 2\cos\(\frac{2 \pi nk}{2N} \)
  \right]
\end{dmath}


Following \cite{shaojohnsondst23}, we have
\begin{dmath}
  X_k
  =
  \sum_{n=0}^{N/2 - 1} X_{2n} \omega_{N/2}^{nk}
  + \omega_N^{k} \sum_{n=0}^{N/4 - 1}x_{4n + 1} \omega_{N/4}^{nk}
  + \omega_N^{-k} \sum_{n=0}^{N/4 - 1}x_{4n - 1} \omega_{N/4}^{nk}
\end{dmath}
and then we notes that the first sum is zero, the second sum is the
transform of $\tilde{y}$, and the third sum is the same as the second
sum in reverse order.

\subsection{DST-II}

\begin{dmath}
  X_k = \sum_{n=0}^{N-1}x_n \sin\left[\frac{\pi}{N+1}\(n+\frac{1}{2}\)(k+1)\right]
\end{dmath}

This transform can be compuated via a length-$4N$ transform with input
\begin{dmath}
  \tilde{x} = \{0, x_0, 0, x_1, 0, \dots, x_{N-1} ,0,  -x_{N-1}, 0, -x_{N-2}\dots , 0,  -x_2, 0, -x_1 \}
\end{dmath}
That is, for $0\leq n < N$,
\begin{eqnarray}
  \tilde{x}_n &= \tilde{x}_{4N - (2n +1)} = 0 \\
  \tilde{x}_{2n + 1} &= x_n \\
  \tilde{x}_{4N - (2n + 1)} &= -x_n.
\end{eqnarray}
and take the negative of the imaginary part of the result of the
Fourier transform for indices $1,\dots,N$.

From From \cite{shaojohnsondst23}, this can be computed from by taking
\begin{align}
  y_n &= x_{2 n} \\
  y_{N - 1 -n} &= -x_{2 n + 1}
\end{align}
computing
\begin{align}
  X_{0} &= \Re{Y_0} \\
  X_{k} &= \Re{\omega_{4N}^k Y_k}, \qquad k = 1,\dots, N/2-1 \\
  X_{N-k} &= -\Im{\omega_{4N}^k Y_k}, \qquad k = 1,\dots, N/2-1 \\
  X_{N / 2} &= \Re{Y_{N/2}}/\sqrt(2)
\end{align}
and then reversing the array.  This can probably be simplified, ie
it's not necessary to reverse the array as a separate stage.

\subsection{DCT-III}

\begin{dmath}
  X_k = \frac{1}{2}x_0
  +\sum_{n=1}^{N-1}x_n \cos\left[\frac{\pi}{N}n\(k+\frac{1}{2}\)\right]
\end{dmath}

This can be computed via a length-$4N$ transform on
\begin{align}
  \tilde{x}_n &= x_n, \qquad n = 0,\dots, N-1 \\
  \tilde{x}_N &= 0\\
  \tilde{x}_{N+1+n} &= -x_{N - n - 1}, \qquad n = 1,\dots, N-1 \\
  \tilde{x}_{2 N + n} &= -x_n, \qquad n = 0,\dots, N-1 \\
  \tilde{x}_{3N} &= 0\\
  \tilde{x}_{3 N + n} &= -x_{N-n}, \qquad n = 1,\dots, N-1
\end{align}
and then taking $1/4$ of the real parts of the odd-indexed outputs
from index 1 to $2N$.

From \cite{shaojohnsondst23}, this can be computed more efficiently
via a length-$N$ real/complex FFT.


\subsection{DST-III}

\begin{dmath}
  X_k = \frac{\(-1\)^k }{2} x_{N-1}
  +\sum_{n=0}^{N-2}x_n \sin\left[\frac{\pi}{N}\(n+1\)\(k+\frac{1}{2}\)\right]
\end{dmath}

This can be computed via a length-$4N$ real/complex FFT with input
\begin{align}
  \tilde{x}_0 &= 0\\
  \tilde{x}_n &= x_n, \qquad n = 1,\dots, N-1 \\
  \tilde{x}_N &= x_{N-1}\\
  \tilde{x}_{N + n + 1} &= x_{N - n - 2}, \qquad n = 1,\dots, N-1 \\
  \tilde{x}_{2N} &= 0\\
  \tilde{x}_{2 N + n + 1} &= -x_n, \qquad n = 1,\dots, N-1 \\
  \tilde{x}_{3N} &= -x_{N-1}\\
  \tilde{x}_{3 N + n + 1} &= -x_{N - n - 2}, \qquad n = 1,\dots, N-1 \\
\end{align}
and taking $1/4$ times the imaginary part of the first $N$ outputs
with odd index.


From \cite{shaojohnsondst23}, this can be computed more efficiently.

\subsection{DCT-IV}

\begin{dmath}
  X_k = \sum_{n=0}^{N-1} x_n \cos\left[\frac{\pi}{N}\(n + \frac{1}{2}\) \(k + \frac{1}{2}\) \right]
\end{dmath}

This can be computed via a length-$8N$ real/complex FFT with 
\begin{align}
  \tilde{x}_{2 n + 1} &= x[n] \\
  \tilde{x}_{4 N - (2 n + 1)} &= -x_n \\
  \tilde{x}_{4 N + 2 n + 1} &= -x_n \\
  \tilde{x}_{8 N - (2 n + 1)} &= x_n
\end{align}
for $n=0, \dots, N-1$, and zero elsewhere.  One then takes $1/4$ times
the real part of the first $N$ values with odd index.

\cite{shaojohnsondst4}, this can be computed more efficiently.

\subsection{DST-IV}

Given $\{x_n\}_{n=0}^{N-1}$,
\begin{dmath}
  X_k = \sum_{n=0}^{N-1}x_n \sin\left[\frac{\pi}{N+1}\(n+\frac{1}{2}\)\(k+\frac{1}{2}\)\right]
\end{dmath}

This can be computed via a length-$8N$ real/complex FFT with 
\begin{align}
  \tilde{x}_{2 n + 1} &= x[n] \\
  \tilde{x}_{4 N - (2 n + 1)} &= x_n \\
  \tilde{x}_{4 N + 2 n + 1} &= -x_n \\
  \tilde{x}_{8 N - (2 n + 1)} &= -x_n
\end{align}
for $n=0, \dots, N-1$, and zero elsewhere.  One then takes $1/4$ times
the imaginary part of the first $N$ values with odd index.


\cite{shaojohnsondst4}, this can be computed more efficiently.
