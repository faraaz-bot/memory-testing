To generate the docx report, one needs the python docx package with a
patch to handle EMF images, which is the only vector-graphics format
that MS Word can support.  PDFs can be converted to EMF images by
first converting to SVG (via pdf2svg) and then using inkscape in
headless mode to convert the SVGs to EMF.  The python-docx package can
then add these to a docx file.

sudo apt install pdf2svg inkscape

mkdir -p ~/src/python/ && cd ~/src/python/
git clone git@github.com:python-openxml/python-docx.git
#python3 setup.py install --prefix=${HOME}/python
export PYTHONPATH=${HOME}/src/python/python-docx
