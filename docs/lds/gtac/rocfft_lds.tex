\begin{abstract}
The performance of bandwidth-limited algorithms strongly depends on
compute memory hierarchy.  In this article, we propose a model for FFT
performance on ROCm GPUs as a function of shared memory (LDS) size and
performance.
\end{abstract}

\keywords{FFT, GPU, LDS, ROCm}

\section{Introduction}

the fast Fourier transforms (FFT) is considered one of the most
important algorithms of the modern era~\cite{strang1994wavelets} and
has a variety of important uses from digital signal
processing~\cite{sorensen1990efficient}, to computational fluid
mechanics~\cite{chatterjee2018scaling}, to machine
learning~\cite{mathieu2013fast}, and many others.  The FFT algorithm,
first fully developed in~\cite{cooley1965algorithm}, reduces the
computational complexity from $N^2$ to $N\log{}N$, and the numerical
error from $\mathcal{O}\(\sqrt{N}\)$ to
$\mathcal{O}\(\sqrt{\log{}N}\)$ ~\cite{gentleman1966fast}.

On modern hardware, for all practical problem sizes, the FFT is
bandwidth-limited.  Moreover, the data dependency diagram is
all-to-all; every point of the output depends on every point of the
input.  Effective data movemnet is an imporant factor in designing
high-performace FFT implementations.  In this article, we explore how
performance on SIMT (single-instruction multiple thread) architectures
such as the GPU, and establish a theoretical performance model to help
understand how changes in local data share (LDS) size affects GPU FFT
performance.
