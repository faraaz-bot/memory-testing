** rocfft

   cmake -G Ninja -DCMAKE_CXX_COMPILER_LAUNCHER=ccache -DCMAKE_CXX_COMPILER=hipcc -DBUILD_CLIENTS=ON -DAMDGPU_TARGETS= -DROCFFT_CALLBACKS_ENABLED=OFF ..
   cmake -G Ninja -DCMAKE_CXX_COMPILER=hipcc -DBUILD_CLIENTS=ON -DAMDGPU_TARGETS= -DROCFFT_CALLBACKS_ENABLED=OFF ..
   cmake -DCMAKE_CXX_COMPILER=hipcc -DBUILD_CLIENTS=ON -DAMDGPU_TARGETS= -DROCFFT_CALLBACKS_ENABLED=OFF ..

** vkfft

   In VkFFT/build:

     cmake -DCMAKE_INSTALL_PREFIX=$HOME/vkfft-install ..

   In rocFFT-misc/riders/vkfft

   make VKFFT_HOME=$HOME/vkfft-install ROCFFT_SRC=$HOME/rocFFT-develop VKFFT_SRC=$HOME/VkFFT

** hipfft (cuda)

   On ixt-rack-60; this builds against CUDA 11.2.

   docker run --rm --tty --interactive --gpus all --volume /home/maemmett:/x rocfft-cuda-perf
   cmake -DCMAKE_CXX_COMPILER=g++ -DCMAKE_BUILD_TYPE=Release -DBUILD_CLIENTS=ON -DBUILD_WITH_LIB=CUDA ..

   To build Docker image:
   cd rocFFT-misc/perf/docker
   docker build -t rocfft-cuda-perf .
