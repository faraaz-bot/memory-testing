* Performance tracking

  export TOP=/x

  export TOP=$HOME
  export PATH=$PATH:$TOP/rocFFT-internal/scripts/perf
  cd $TOP/rocFFT-misc/docs/update2021

  export ROCFFT_RIDER=$TOP/rocFFT-internal/build/clients/staging/rocfft-rider
  export HIPFFT_RIDER=$TOP/hipFFT-internal/build/clients/staging/hipfft-rider
  export VKFFT_RIDER=$TOP/rocFFT-misc/riders/vkfft/vkfft-rider

  sudo apt install python3-numpy python3-pandas
  pip3 install plotly

** rocfft

* Building riders

  git clone git@github.com:ROCmSoftwarePlatform/rocFFT-internal.git
  git clone git@github.com:ROCmSoftwarePlatform/rocFFT-misc.git
  git clone git@github.com:ROCmSoftwarePlatform/hipFFT-internal.git
  git clone git@github.com:DTolm/VkFFT.git

** rocfft

   cmake -G Ninja -DCMAKE_CXX_COMPILER_LAUNCHER=ccache -DCMAKE_CXX_COMPILER=hipcc -DBUILD_CLIENTS=ON -DAMDGPU_TARGETS= -DROCFFT_CALLBACKS_ENABLED=OFF ..

** vkfft

   In VkFFT/build:

     cmake ..

   In rocFFT-misc/riders/vkfft

     make VKFFT_HOME=$TOP/VkFFT ROCFFT_HOME=$TOP/rocFFT-internal

** hipfft (cuda)

   On ixt-rack-60; this builds against CUDA 11.2.

   docker run --rm --tty --interactive --gpus all --volume /home/maemmett:/x rocfft-cuda-perf
   cmake -DCMAKE_CXX_COMPILER=g++ -DCMAKE_BUILD_TYPE=Release -DBUILD_CLIENTS=ON -DBUILD_WITH_LIB=CUDA ..
