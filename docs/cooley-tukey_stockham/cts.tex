\section{Radix-2 FFTS}

Notation:
\begin{dmath}
  \label{DFT}
  X_k = \sum_{n=0}^{N-1} x_n \omega_N^{nk}
\end{dmath}
\begin{dmath}
  \omega_N = e^{\frac{-2 \pi i}{N}}
\end{dmath}

The DIT algorithm breaks RHS of equation~\eqref{DFT} into into even
and odd parts; the DIF algorithm breaks it into halves.  The DIF
algorithm has the bit-reversal at the input, and the DIT algorithm as
the bit-reversal at the output. (See Sloan 1.9.5).

\section{Cooley--Tukey}

\subsection{DIT}

The Cooley--Tukey algorithm was the first FFT algorithm developed.
For $N=2^p$, it involves $p$ butterfly stages followed by a
reshuffling or ``bit-reversal'' stage.

\begin{dmath}
  X_k
  = \sum_{n=0}^{N-1} x_n \omega_N^{nk}
  = \sum_{n=0}^{N/2-1} x_{2n} \omega_N^{2nk}
  +\sum_{n=0}^{N/2-1} x_{2n+1} \omega_N^{\(2n+1\)k}
  = \sum_{n=0}^{N/2-1} x_{2n} \omega_N^{2nk}
  +\sum_{n=0}^{N/2-1} x_{2n+1} \omega_N^{2nk}\omega_N^{k}
  = \sum_{n=0}^{N/2-1} x_{2n} \omega_{N/2}^{nk}
  +\omega_N^{k}\sum_{n=0}^{N/2-1} x_{2n+1} \omega_{N/2}^{nk}
  = \mathcal{F}\[\{x_{2n}\}_{n=0}^{\frac{N}{2}-1}\]_k
  +\omega_N^{k}\mathcal{F}\[\{x_{2n+1}\}_{n=0}^{\frac{N}{2}-1}\]_k
\end{dmath}

\subsection{DIF}



\begin{dmath}
  X_k
  = \sum_{n=0}^{N-1}  x_n \omega_N^{nk}
  = \sum_{n=0}^{N/2-1} x_n \omega_N^{nk} + \sum_{n=N/2}^{N-1} x_n \omega_N^{nk}
  = \sum_{n=0}^{N/2-1} x_n \omega_N^{nk}
  + \sum_{n=0}^{N/2-1} x_{n + \frac{N}{2}} \omega_N^{\(n + \frac{N}{2}\)k}
  = \sum_{n=0}^{N/2-1} x_n \omega_N^{nk}
  + \omega_N^{\frac{N}{2}k} \sum_{n=0}^{N/2-1} x_{n + \frac{N}{2}} \omega_N^{nk}
  = \sum_{n=0}^{N/2-1} x_n \omega_N^{nk}
  + \(-1\)^k \sum_{n=0}^{N/2-1} x_{n + \frac{N}{2}} \omega_N^{nk}
\end{dmath}
Which implies that
\begin{dmath}
  X_{2k}
  = \sum_{n=0}^{N/2-1} x_n \omega_N^{n2k}
  + \(-1\)^{2k} \sum_{n=0}^{N/2-1} x_{n + \frac{N}{2}} \omega_N^{n2k}
  = \sum_{n=0}^{N/2-1} x_n \omega_{N/2}^{nk}
  + \sum_{n=0}^{N/2-1} x_{n + \frac{N}{2}} \omega_{N/2}^{nk}
\end{dmath}
and
\begin{dmath}
  X_{2k+1}
  = \sum_{n=0}^{N/2-1} x_n \omega_N^{n\(2k+1\)}
  + \(-1\)^{2k+1} \sum_{n=0}^{N/2-1} x_{n + \frac{N}{2}} \omega_N^{n\(2k+1\)}
  = \omega_N \(\sum_{n=0}^{N/2-1} x_n \omega_{N/2}^{nk} 
  - \sum_{n=0}^{N/2-1} x_{n + \frac{N}{2}} \omega_{N/2}^{nk} \),
\end{dmath}
so
\begin{dmath}
  \{X_{2k}\}_{k=0}^{N/2-1}
  =
  \mathcal{F}_{N/2}\[\{x_n\}_{n=0}^{N/2 - 1}\]
  + \mathcal{F}_{N/2}\[\{x_n\}_{n=N/2}^{N - 1}\]
\end{dmath}
\begin{dmath}
  \{X_{2k+1}\}_{k=0}^{N/2-1}
  =
  \omega_N\(\mathcal{F}_{N/2}\[\{x_n\}_{n=0}^{N/2 - 1}\]
  - \mathcal{F}_{N/2}\[\{x_n\}_{n=N/2}^{N - 1}\]\).
\end{dmath}

\section{Stockham}

The Stockham algorithm does not have an explicit bit-reversal stage.
Instead, each butterfly is combined with a partial re-ordering.  The
butterflies are equivalent to the relevant Cooley--Tukey alrogithm.
The data flow is shown in Figure~\ref{stockham-dit}.
